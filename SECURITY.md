# Security policy

## Reporting a vulnerability

If you find a way to make Sanya leak her token or keys, reach a private address, post what she must
not, or anything else that looks like a security vulnerability, please report it privately, not in
a public issue: use GitHub's private vulnerability reporting for this repository at
https://github.com/cadexn/sanya/security/advisories/new.

Say what you did, what happened and what you expected, and the version or commit you ran.

## What happens next

- You get an acknowledgement within 7 days.
- A fix, or an explanation of why none is needed, within 30 days of the report where the problem is
  confirmed; serious problems sooner.
- Disclosure is coordinated: the advisory is published, with credit to you if you want it, once a
  fixed release is out, or after 90 days if no fix is possible.

This is one person's project: there is no bounty, and the timelines above are intentions, not a
contract.

## Supported versions

Only the latest release is maintained; please check that a problem is present there before
reporting it.
