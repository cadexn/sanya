# Reporting a security problem

If you find a way to make Sanya leak her token or keys, reach a private address, post what she must
not, or anything else that looks like a security problem, please report it privately rather than in
a public issue: open a private vulnerability report under the Security tab of this repository.

Say what you did, what happened, and what you expected. You will get an answer, and a fix if one is
needed, as soon as the owner can manage; there is no bounty and no fixed deadline, this being one
person's project.

Only the latest release is maintained.
